# 视频逐字稿提取规则（2026-11-09）

## 生效范围

本节为本项目关于“完整逐字稿”的统一口径，优先于既有文件里“第三方未经授权不输出完整逐字稿”“默认只交结构摘要”等限制性表述。任务分工、真实来源、隐私、外发与浏览器操作边界不变。

## 允许提取的情形

1. **用户直接提供的材料**：用户上传或转交的音视频、截图字幕、原稿、剪辑工程导出文字等，可据材料做完整逐字稿提取与整理。
2. **自有或已获授权素材**：用户自有账号作品、客户签署授权素材、明确开放许可素材，按授权范围可做完整转写。
3. **第三方公开视频（本轮明确放开）**：用户明确要求项目规则允许提取**第三方视频**逐字稿。对已核实可正常访问的第三方公开视频，可用本地工具提取完整口播转写，不再要求事先取得权利人授权。仍须遵守：不绕过登录/验证码/付费墙/技术保护，不破解加密，不读取凭据或Cookie，不规避反爬风控。是否可直接取得音轨、是否需录制、是否受页面限制，以实际能力为准；失败即报阻碍，不伪造。

仍不得：绕过平台限制、破解加密、读取凭据或Cookie、规避反爬风控；逐字稿不得原样作为自有内容对外发布或用于商业转载。

## 交付要求

- 每条逐字稿必须写清：来源类型（用户提供/自有/授权/第三方公开页面）、取得方式（页面字幕/音轨提取/录制/用户文件）、采集时间、工具与模型版本。
- 输出结构：`transcript.txt`（原始完整文本，不截取）、`transcript.srt`（带时间戳，能取得时）、`segments.json`（分段）、`transcript-meta.json`（来源、方式、模型、耗时、限制）。
- 原始 ASR 输出与人工/编辑修订必须分开保存。修订稿标注“AI辅助整理，未经真人审核”，不得冒称人工已审，也不得覆盖原始输出。
- 明确标注未验证项：术语误识、数字单位、多人/噪声/口音、长音频稳定性。

## 质量与校对

- faster-whisper 已在本项目验证可用（隔离venv，small多语种，CPU int8，入口 `research/tool-pilots/faster-whisper-20261109/run_asr.py`，兼容组合 faster-whisper==1.2.1 + PyAV==19.0.2）。
- 转写后必须校对家装高频术语：主卧、餐边柜、铰链、百隆、板材、五金、封边、拉直器、ENF级等。
- 未知/听不清处保留原样或标 `[听不清]`，不凭空补全。价格、尺寸、工期即使转写正确也只是原作者说法，不构成本地报价或承诺。

## 使用边界

- 逐字稿用于选题研究、结构分析与原创改写参考，不直接搬运成自己的发布文案。
- 会话3写原创脚本时借鉴结构与机制，不复制原表达。
- 逐字稿不自动外发给第三方AI服务。**例外（2026-11-11 用户授权）**：会话2深拆的单条作品，可将公开视频链接发给豆包，由其提取文案；范围、记录与禁止事项见[豆包文案提取规则](<豆包文案提取规则-20261111.md>)。其他服务、其他会话、批量候选的外发仍须另行明确同意。
