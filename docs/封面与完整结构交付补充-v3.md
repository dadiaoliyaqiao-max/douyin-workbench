# 封面与完整结构交付补充｜v3

## 用户于2026-11-09确认

- 选片表每个视频都要有封面图。
- 深拆每条都要有封面，以及开头、主体、收尾各1张视频截图。
- 用户在`deep_script_scope_v3`选择“原视频的完整结构梳理，不要逐字稿”。不据此启动会话3或改写原创剧本。

## 选片表要求

对已有50条候选补齐真实原封面，并在新版选片表直接显示图片、保留可点击作品链接。B/H/C编号及作品ID映射不变，分类/排序/冻结窗口不变，不重跑新一轮候选采集。

可使用公开视频作品卡片、主页/搜索卡片的真实封面资源或相应截图，必须核对作品ID并保存来源、取得时间。不能拿任意视频帧冒充原封面，不能用占位图冒充已取得。未取得的逐条列缺口，封面完整性不通过；禁止因字段poster为空就断言作品无封面。为清单展示可生成保留纵横比的预览图，点击可看原图/视频。

## 深拆要求（先升级B02样板）

1. 封面实图。
2. 开头、主体、收尾各1张真实代表截图，直接嵌入卡片，标实际媒体时点、时长与证据来源。既有可信图片可复用。截图必须与本作品、该段内容对应；页面界面、加载占位、误截图不计。
3. 完整结构梳理：通过实际公开页面观察、可取得字幕及画面信息，按时间顺序列全片主要段落、各段要点和衔接逻辑，用自行转述及必要短引。**2026-11-09规则更新**：如需完整口播逐字稿，按[逐字稿提取规则](<逐字稿提取规则.md>)执行，实际取得音轨或字幕材料后转写，标来源/方式/时间/工具，原始与修订分开；不得据画面推测口播，也不得用摘要冒称完整转写。
4. 三张代表图只是展示证据，不自动证明已观察全片。不得从旧7帧推测所有中间内容、完整口播或结尾CTA。覆盖不足、音频/字幕不可得致关键段无法判断时，明确列出未核实区间与内容，完整性标partial/false，不套模板补齐。
5. 评论需求、本地适配建议、不可照搬点和待确认项继续保留，事实与推断/建议分开。不承诺原片观点或结构机制已证明获客效果。

## 管理与版本

旧v2选片数据、B02试拆卡与旧批次事实保留。会话2创建独立v3业务产物及素材，不能把原v1批次改为已通过。修订时间用实际时钟，不覆盖原采集/评论采样时间。

执行仅由原会话2承担；总管只派工、维护管理记录、接终态回执后轻量验收，不执行采集、转写、清洗或生成业务报告。仍禁读凭据、绕过登录/验证码/付费墙/技术保护；本地已部署的 faster-whisper 转写工具按逐字稿规则可用，未经用户明确同意不得新增外发或大型依赖。
