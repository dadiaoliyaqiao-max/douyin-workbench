# 浏览器桥接（Edge / Chrome）

本项目通过两个**本机扩展 + 本机 relay** 操控浏览器，只读为主，不读取 Cookie/密码库。

## 架构

```
DSH / 脚本（python client.py）
   │  POST /rpc
   ▼
本机 relay（node）
   ├─ 127.0.0.1:8788  ← DSH Edge Bridge 扩展（Edge 研究浏览器）
   └─ 127.0.0.1:8787  ← DSH Chrome Bridge 扩展（Chrome 运营浏览器）
   ▼
真实浏览器标签页（chrome.debugger / CDP）
```

- 两个扩展都由安装脚本创建桌面快捷方式时通过 `--load-extension` 自动加载，无需上商店。
- relay 加入 Windows 开机启动；也可手动运行 `bin\start-bridges.ps1`。
- 日志：`logs\edge-bridge.log`、`logs\chrome-bridge.log`。

## 客户端

| 脚本 | 端口 | 用途 |
|---|---|---|
| `scripts/edge-bridge/client.py` | 8788 | 会话1/2/5 研究操作 |
| `scripts/chrome-bridge/client.py` | 8787 | 会话4 运营账号操作 |

常用命令：

```powershell
python scripts\edge-bridge\client.py status
python scripts\edge-bridge\client.py ping
python scripts\edge-bridge\client.py tabs
python scripts\edge-bridge\client.py new-tab "https://www.douyin.com/"
python scripts\edge-bridge\client.py shot 123 "research\shot.png"
python scripts\chrome-bridge\client.py status
```

## 边界

- 默认只读：读取页面文本/标题/截图；点击、导航等会改变页面状态的操作仅在明确需要时使用。
- 不读取浏览器密码库、Cookie 文件、历史数据库。
- 登录、扫码、验证码由用户本人完成。
- 任何一个桥不可用都要如实标“未接通”，不能假装已采集。
