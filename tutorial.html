① 安装：把这句指令发给 DSH 就行

不用下载 ZIP。新开一个 DSH 聊天，把下面整段复制发给它：

请帮我安装「抖音五模块工作台」：
1. 从 GitHub 公开仓库 https://github.com/dadiaoliyaqiao-max/douyin-workbench 克隆到 D:\DouyinWorkbench；如果目录已存在，先备份 data、batches、research、reviews、scripts-output 再更新。
2. 运行 install.ps1（PowerShell，自动检测 DSH / Edge / Chrome / Node / Python，装好两个浏览器扩展，并把桥接服务设为开机启动）。
3. 安装完成后检查 Edge 8788 和 Chrome 8787 两个桥接是否连通，告诉我两个桌面快捷方式怎么登录。
4. 再引导我在 DSH 新建 5 个工作聊天并运行 configure-sessions.ps1 绑定会话。
5. 不要读取或上传任何密码、Cookie；缺 DSH / Node / Python 时停下告诉我缺什么。
安装脚本会自动：检测环境 → 复制程序 → 创建「研究浏览器（Edge）」和「运营浏览器（Chrome）」两个快捷方式（自动加载扩展）→ 桥接开机自启 → 初始化空对标账号库 → 注册五模块侧栏插件。
如果这台机器的 DSH 没有命令执行权限，才需要手动下载安装包；正常情况下上面的指令就够了。

② 两个浏览器：扫码登录即可

桌面快捷方式登录账号给哪个会话用
研究浏览器（Edge）抖音研究小号会话1 对标账号、会话2 参考视频、会话5 情报
运营浏览器（Chrome）运营账号（你们自己的号）会话4 自有账号复盘

双击快捷方式 → 扫码登录。以后只用这两个快捷方式开浏览器，扩展和登录态才会带对。

项目不会保存你的密码；登录必须本人扫码。账号不对时会话会停下来报错，不会继续采集。

③ 建 5 个会话：新开聊天，粘一句话

在 DSH 里新建 6 个聊天：1 个总管（当前聊天）+ 5 个模块聊天。每个聊天打开同一个工作目录（默认 D:\DouyinWorkbench）。

聊天新建聊天后，把这段发给它
总管（当前）你是总管：只做需求确认、派工、验收和汇报；采集、拆解、写稿、复盘都交给会话1-5。先读 AGENTS.md。
会话1 对标账号你是会话1｜对标账号。先确认 Edge 登录的是研究小号。只负责查我给你的对标账号：每个账号要真实首页截图、可点击主页链接、上次分析后的新增视频趋势和评论情况；写 data/benchmarks.json 和 research/benchmarks/。我不给账号时不要自己猜。
会话2 参考视频你是会话2｜参考视频。先确认 Edge 登录的是研究小号。每轮快采50条：跨行业15（只取近72小时）+对标20+家居15（六个自然月）；评论优先。报告保持原表格，顶部加总体分析，每条加一句入选原因。所有深拆必须用豆包【新工作任务】→【工作】取完整逐字稿并纳入分析。
会话3 原创剧本你是会话3｜原创剧本。等用户选片交接后再写；演示只保留：具体剧本（分镜）、口播文案、标题备选、封面建议，编号从“一”开始。不确定的价格/工期/效果不编；不代发。
会话4 复盘你是会话4｜自有账号复盘。先确认 Chrome 登录的是运营账号。按发布后窗口拉数据，逐条作品诊断，并结合对标账号、参考视频、情报做复盘，给2-4个可检验实验；不承诺流量。
会话5 情报你是会话5｜抖音规则与增长情报。先确认 Edge 登录的是研究小号。查官方规则/功能/案例；标题写结论、每条给来源链接、顶部给总体分析与建议；不安装监测、不设定时。
更细的职责和各输出目录在 会话说明/ 里；上面这段足够开始干活。

④ 五模块工作台：每个按钮干什么

4.1 工作台总览

总管聊天右侧的「五模块工作台」：五张卡，每张卡两个按钮
按钮功能
查看报告打开该模块最新报告（PPT 演示 / 原文两种视图）；原创剧本是「查看 / 编辑」，可直接改 Markdown 存新版本。
更新模块向对应会话派一次“更新”任务（例如参考视频更新会去采新一轮 50 条）。
刷新状态只读刷新卡片，不会唤醒模型、不会派任务。

4.2 参考视频卡片：四个按钮

左：未拆解 → 显示【拆解】；中：拆过 → 变绿【已拆解】；右：点【已拆解】看逐字稿
按钮功能
查看视频打开抖音原视频（新标签页）。
拆解视频还没拆过时出现。点击派给会话2做深拆：全片结构观察 + 评论抽样 + 豆包完整逐字稿 + 真实封面。
已拆解拆过的视频按钮变绿。点击打开详情：最新 revision、豆包逐字稿全文（原始稿＋修订稿）、自查结果、拆解卡片。
做原创剧本没拆解：弹窗提示必须先拆解，不能跳过。
已拆解：弹窗让你填写「本次做剧本要求」（≤2000 字），然后派给会话3 创作；没写要求就按默认账号定位创作。

报告往下滑还有「已拆解逐字稿」区块，可直接展开看全文。

4.3 原创剧本：调整剧本

演示底部蓝色【调整剧本】→ 填要求 → 会话3出新版本（保留旧版）
位置功能
演示内容只显示四类：具体剧本（分镜）、口播文案、标题备选、封面建议；标题从“一、二、三、四”重新编号。
调整剧本点开填写修改要求（如“口播缩短到30秒、开头改预算痛点”），派给会话3 基于当前稿生成新版本，不覆盖旧版本。
查看 / 编辑在工作台卡片上：直接编辑 Markdown，保存为新版本。

4.4 对标账号 / 复盘 / 情报

卡片按钮功能
对标账号打开主页 / 查看详情打开抖音主页；或看该账号首页截图、最新分析、最近新增视频、评论情况。一个账号一张卡。
复盘查看报告 / 更新模块看深度复盘；派会话4 更新数据并复盘。
情报查看报告 / 更新模块看情报报告（每条带来源链接）；派会话5 更新。

⑤ 每天怎么用（一轮循环）

  1. 更新参考视频：工作台点「参考视频 · 更新模块」，等会话2 交 50 条报告。
  2. 你选片：看报告，明确告诉总管选哪几条（例如“选 B02、B10、S01”）；总管会记录并生成交接。
  3. 做剧本：在参考视频卡点【做原创剧本】填要求；剧本出来后不满意就点【调整剧本】继续改。
  4. 拍摄发布后复盘：把作品 ID 告诉会话4，它拉数据复盘；会话5 定期更新情报；然后进入下一轮。

⑥ 常见问题

按钮点了没反应 / 提示桥接未连接

在安装目录运行 bin\start-bridges.ps1，并用桌面快捷方式重新打开浏览器；仍不行看 logs\ 日志。

工作台卡片没有出现

需要先绑定 5 个会话（安装指令第 4 步的 configure-sessions.ps1），然后完全重启 DSH。不绑定也能按第③节手动用 5 个聊天。

提示账号不符 / 要求重新登录

会话1/2/5 只认 Edge 研究小号，会话4 只认 Chrome 运营账号。用对应快捷方式扫码登录正确账号再重试。

豆包说打不开链接

必须用豆包【新工作任务】→【工作】模式，普通聊天打不开抖音链接；把完整提示词和链接一起发。
