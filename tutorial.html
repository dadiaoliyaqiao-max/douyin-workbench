1. 安装前准备

需要说明
Windows 10 / 11（64 位）当前发布包只支持 Windows。
DSH 桌面版（DeepSeek Harness）同事之间使用的 AI 工作台。请先安装、至少启动一次。本项目的规则、会话和侧栏插件都跑在 DSH 里。
Microsoft Edge研究浏览器：登录抖音研究小号，供会话1/2/5 使用。
Google Chrome运营浏览器：登录运营账号，供会话4 复盘使用。
能上网抖音、豆包、GitHub（可选）等。
安装脚本会自动使用 DSH 自带的 Node.js 和 Python，不需要你单独配置环境；如果 DSH 没装，脚本会提示先安装。
浏览器登录必须由你本人扫码/输密码完成。本项目不会、也不能替你保存抖音密码或 Cookie。

2. 安装（一键脚本）

  1. 下载发布包：从 GitHub 下载 ZIP，解压到一个普通目录，例如 D:\DouyinWorkbench-install。
  2. 运行安装：在解压目录右键 install.ps1 →「使用 PowerShell 运行」。
    若没有该菜单，打开 PowerShell 进入目录执行： 
    powershell -ExecutionPolicy Bypass -File .\install.ps1
  3. 阅读检测结果：脚本会逐项检测 Windows、DSH、Edge、Chrome、Node、Python，并显示 [OK] / [!]。
  4. 等待文件复制：默认安装到 %USERPROFILE%\DouyinWorkbench，可用参数指定： 
    powershell -ExecutionPolicy Bypass -File .\install.ps1 -InstallDir "D:\DouyinWorkbench"
  5. 浏览器步骤：脚本会创建两个桌面快捷方式、独立浏览器配置目录、自动加载扩展；询问时按回车会打开两个浏览器让你登录。
  6. 完成：脚本自动注册 DSH 侧栏插件（默认关闭）、把桥接服务加入开机启动、打开本教程。

安装脚本为你做了什么

3. 两个浏览器与登录

安装完成后桌面会有两个快捷方式。以后只用这两个快捷方式开浏览器，扩展和登录态才会带对。

研究浏览器（Edge 小号）

用途：会话1 对标账号、会话2 参考视频、会话5 情报。

登录：抖音研究小号；打开 https://www.douyin.com/user/self 可看到账号名和抖音号。

扩展：DSH Edge Bridge；桥接端口 8788

运营浏览器（Chrome 运营账号）

用途：会话4 自有账号复盘。

登录：你们自己的运营账号；打开 https://creator.douyin.com/ 查看后台。

扩展：DSH Chrome Bridge；桥接端口 8787

登录步骤

  1. 双击「研究浏览器（Edge 小号）」→ 扫码登录研究小号。
  2. 双击「运营浏览器（Chrome 运营账号）」→ 扫码登录运营账号。
  3. 验证扩展：Edge 地址栏输入 edge://extensions、Chrome 输入 chrome://extensions，应看到对应 Bridge 扩展已启用。
  4. 验证桥接（在安装目录执行，使用 DSH 自带 Python 或系统 Python）： 
    python scripts\edge-bridge\client.py status
python scripts\chrome-bridge\client.py status
    返回 connected=true 即通。若失败见 FAQ。
登录检查同时是项目规则：会话1/2/5 只认研究小号；会话4 只认运营账号。账号不符时模块会停止并报 blocked，不会继续采集。

4. 创建 5 个工作聊天

在 DSH 里新建 6 个工作聊天：1 个总管 + 5 个模块。每个聊天打开同一个工作目录（安装目录）。

聊天启动说明文件职责
总管（当前聊天）AGENTS.md需求确认、派工、验收、选片记录、结果汇报
会话1会话说明/会话1-对标账号.mdEdge 查用户给的对标账号，出账号库与趋势报告
会话2会话说明/会话2-参考视频.md每轮 50 条参考视频，深拆，交接给会话3
会话3会话说明/会话3-原创剧本.md读交接，写可拍原创剧本
会话4会话说明/会话4-自有账号复盘.mdChrome 读运营账号数据，做深度复盘
会话5会话说明/会话5-规则与增长情报.md官方规则/功能/案例情报

怎么启动

  1. 打开 会话说明/会话1-对标账号.md，把「可直接发给该会话的启动指令」整段复制给会话1。
  2. 对会话2、3、4、5 重复同样操作，各自用对应文件。
  3. 总管聊天保持为当前聊天，负责汇总。
每个聊天的完整历史不会自动互通；共享工作目录里的文件才是交接依据。所以务必让 6 个聊天都打开同一个安装目录。
不要让每个模块去猜别人的进度。报告、批次数据、交接文件都落在目录里，总管按文件验收。

5. 给出你的对标账号

对标账号由用户自己提供，安装包不预置任何账号，也不会自动猜。

方式 A（推荐）

直接在总管或会话1 里发：账号名称、抖音号或主页链接（能附上大致粉丝量更好）。会话1 会用 Edge 打开原页核验身份，再写入账号库。

方式 B

编辑 data/benchmarks.json，把名称/抖音号/主页链接写进 accounts 数组；再让会话1 核验。

建议先给业务信息：主营细分（全屋定制/整装/设计/软装等）、服务城市、目标（同城获客/个人 IP/带货）。可以填在 data/business_profile.json，也可以直接告诉总管。

对标账号数量不限，但会话2 的 benchmark 配额是 20 条；用户没确认的候选不能被当作 confirmed。

6. 每天怎么用

一轮完整流程

  1. 情报/对标更新（可选）：会话5 出最新规则情报；会话1 更新对标账号的最新视频趋势与评论。
  2. 会话2 采参考：每轮 50 条 = 跨行业热门15 + 对标账号20 + 家居家装15；非家居只看近72小时，家居/对标看六个自然月；评论优先。
  3. 用户选片：你在 50 条里挑要做的；明确说“选 B02/B10、H04、S01 自选”等。总管用 scripts/workspace.py select 记录你的原话并生成不可静默改动的交接。
  4. 会话3 写剧本：读交接写原创可拍稿；侧栏可点【调整剧本】填写要求继续改。
  5. 拍摄发布：你们自己拍、自己发；发布后把作品 ID 补进 scripts-output/<批次>/publication-map.json。
  6. 会话4 复盘：按发布后窗口拉数据，做深度复盘（结合对标/参考/情报），给下一轮实验建议。
  7. 回到第 2 步继续下一轮。

如果启用了五模块工作台（见第 13 节）

总管聊天右侧会出现【五模块工作台】卡片：查看每张卡的最新报告、点“查看报告”看 PPT 式报告；参考视频卡可【查看视频】【拆解】【做原创剧本】，剧本卡可【调整剧本】。

7. 五模块详解

模块输入核心产出硬性要求
会话1 对标账号用户给的对标账号名称/链接；上次分析截止账号卡片（首页截图＋主页链接）、新增视频趋势、评论情况、分析报告真实截图与链接；只读；登录研究小号；不重复会话2 的拆解

会话4 自有账号复盘Chrome 已登录运营账号；脚本→作品映射逐条作品诊断、对标/参考/情报三项对照、2-4 个实验登录运营账号；区分统计口径；不做因果断言
会话5 情报抖音官方/创作者中心/媒体来源结论式标题＋每条来源链接＋顶部总体分析与建议官方原文优先；公示≠生效；不装监测、不设定时
总管（你当前聊天）只做需求确认、派工、验收和汇总，不亲自采集/写稿/复盘；有问题汇总后交回对应模块处理。

8. 核心规则速查

参考视频 50 条

  • 窗口：启动日前六个自然月；月底回退到目标月最后一天；不跨轮沿用旧截止日。
  • 配额：跨行业热门15 + 对标账号20 + 家居家装15 = 50；同一作品 ID 只计一次。
  • 排序：同类里评论数优先、点赞数次之，同条件近期优先。
  • 非家居只取冻结的近 72 小时；美食/吃播不纳入。
  • 不足 50 条就如实报缺口，不凑数、不扩窗。
  • 候选报告版式保持原表格；顶部加总体分析；每条一句“入选原因（简短）”。

登录账号门禁

  • 会话1/2/5：必须确认 Edge 登录的是研究小号；不符/未登录立即停止并报 blocked。
  • 会话4：必须确认 Chrome 登录的是运营账号。
  • 任何人不得复制 Cookie、读密码库；登录/扫码/验证码由本人完成。

所有拆解视频必须做逐字稿

  1. 打开豆包 → 点【新工作任务】→ 选【工作】（普通聊天打不开抖音链接）。
  2. 把公开链接和这段话一起发送：
    请提取这个抖音视频的完整口播文案（逐字稿），不要只做摘要，尽量逐句输出，并标注听不清的地方：
  3. 保存原始逐字稿、meta（工作模式/对话URL/提示词/局限）和修订稿；把逐字稿纳入拆解卡片与分析。
  4. 没取得逐字稿 = 这条拆解不能标完成；不得用其他 AI 冒充、不得用旧摘要代替。

自选视频（用户直接给的链接）

  • 由会话2 只读解析作品 ID，做完整深拆后追加到参考视频报告，分类=【自选】，编号 S01 起。
  • 自选不计入 15/20/15 配额；与已有 50 条 ID 重复时不重复建卡。

做原创剧本 / 调整剧本

  • 没拆解过的视频：点【做原创剧本】会弹窗要求先拆解，不能跳过。
  • 已拆解：弹窗让你填写“本次做剧本要求”，随任务交给会话3（≤2000字）。
  • 剧本演示只展示：具体剧本（分镜）、口播文案、标题备选、封面建议；标题从“一”开始编号。
  • 演示底部【调整剧本】：填写调整要求，派给会话3 基于当前稿生成新版本（保留旧版，不覆盖）。
  • 剧本默认是草稿；发布、投流等操作必须另行明确授权。

情报与复盘

  • 情报：标题=结论、每条有来源链接、顶部放总体分析与建议；官方原文优先；公示/征求意见不等于已生效。
  • 复盘：逐条作品诊断＋对标对照＋参考机制对照＋情报对照＋2-4 个可检验实验；不承诺流量或成交。

完整规则：AGENTS.md、docs/、会话说明/。

10. 常见问题

桥接 status 报 relay_unreachable / 连不上

① 端口是否在听：Get-NetTCPConnection -LocalPort 8788；② 运行 bin\start-bridges.ps1；③ 看对应扩展是否启用、浏览器是否用桌面快捷方式打开的；④ 看 logs\ 日志。

浏览器里看不到 DSH Edge/Chrome Bridge 扩展

确认是从桌面快捷方式启动的（快捷方式带 --load-extension）。若手动开了浏览器，关掉后用快捷方式重开。Edge 看 edge://extensions，Chrome 看 chrome://extensions。

提示“未找到 Node.js / Python”

安装并启动一次 DSH 桌面版，让它自带运行时落盘，然后重跑 install.ps1；或自行安装 Node 20+ / Python 3.10+ 后重跑。

五模块工作台没有出现

默认是关闭的，见第 13 节。需要先运行 configure-sessions.ps1 绑定会话，然后完全重启 DSH。不启用也不影响手动使用 5 个聊天。

账号不符 / 提示重新登录

会话1/2/5 只认研究小号，会话4 只认运营账号。请用对应浏览器扫码登录正确账号后重试；不要在同一浏览器里切换多个抖音号混用。

豆包说打不开链接 / 只给摘要

必须用豆包【新工作任务】→【工作】模式，普通聊天打不开抖音链接。把完整提示词和链接一起发送；仍失败就如实标 blocked，不要用其他 AI 冒充。

Windows 拦截 install.ps1

这是未签名脚本的 SmartScreen 提示：右键属性勾选“解除锁定”，或“更多信息→仍要运行”；也可在 PowerShell 里用 Unblock-File。

数据放在哪里？会丢吗？

所有业务数据在安装目录的 batches/ research/ reviews/ scripts-output/ data/。重装/升级只覆盖程序文件，这些目录建议定期备份。

11. 隐私与安全

  • 不保存密码：抖音登录完全由你本人在两个浏览器里扫码完成。
  • 不读 Cookie/密码库：桥接只通过浏览器扩展执行读取类命令，不读取凭据文件。
  • 默认只读：发布、删改内容、评论私信、关注、投流、支付等外部操作，必须另行明确授权。
  • 数据在本地：报告、截图、逐字稿都保存在安装目录；上传 GitHub 时切勿把 batches/ research/ reviews/ data/ 一起提交。
  • 逐字稿标注：豆包提取属 AI 辅助整理、未经真人审核，交付必须保留标注。

13. 进阶：启用五模块工作台（可选）

工作台能把五张卡片、报告阅读、拆解/做剧本/调整剧本按钮直接放进 DSH 总管聊天右侧。它需要把 5 个 DSH 会话 ID 绑定到本机配置。

前提

  1. 已按第 4 节创建 6 个聊天。
  2. 能拿到每个聊天的会话 ID（session- 开头）。通常在聊天的会话信息/设置里可以复制；如果找不到，先跳过本节，手动模式完全可用。

步骤

  1. 在安装目录运行： 
    powershell -ExecutionPolicy Bypass -File .\configure-sessions.ps1
  2. 按提示依次粘贴：总管、会话1、会话2、会话3、会话4、会话5 的会话 ID。留空则放弃。
  3. 脚本会生成 config/session-dispatch-v3.json 并启用插件。
  4. 完全退出并重新启动 DSH（不是刷新页面）。
  5. 打开总管聊天，右侧应出现【五模块工作台】卡片。
绑定错误会导致派工发错聊天。不确定 ID 时不要绑定；工作台显示异常时改回 disabled: true 或重跑安装脚本即可。

14. 升级与卸载

升级

  1. 下载新版 ZIP，解压到新目录。
  2. 先把旧安装目录里的 batches/ research/ reviews/ scripts-output/ data/ 复制出来备份。
  3. 关闭 DSH，运行新版 install.ps1，安装到同一目录（脚本不会删除业务数据）。
  4. 重新启动 DSH；如绑定过会话，重跑一次 configure-sessions.ps1。

卸载

  1. 删除桌面两个浏览器快捷方式、启动项里的「抖音工作台桥接服务」。
  2. 在 DSH 的 cordis.patch.yml 删除 douyin-workbench 那段 insert。
  3. 删除安装目录。如需彻底清登录态，删除 browser-profiles/（会退出两个抖音账号）。
建议每轮批次结束后备份一次 batches/ 和 data/；这些是项目最值钱的资产。
