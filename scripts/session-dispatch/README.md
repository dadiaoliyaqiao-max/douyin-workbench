# 五会话调度插件（可选高级能力）

本目录是运行在 DSH 宿主内的插件代码：让总管聊天把任务派给 5 个固定模块聊天，并在终态回执时通知总管。

## 组成

| 文件 | 作用 |
|---|---|
| `core-v3.mjs` | 五目标常量、任务账本、配置校验、边锁 |
| `host-v4.mjs` | 宿主侧派工/查状态 RPC，原生 queue 投递 |
| `ui-bridge.mjs` | 供侧栏插件读取调度状态 |

## 启用步骤

1. 安装脚本已把插件写进 DSH 的 `cordis.patch.yml`（`id: douyin-workbench`，默认 `disabled: true`）。
2. 在安装目录运行 `configure-sessions.ps1`，粘贴总管与会话1-5 的会话 ID。
3. 完全重启 DSH。
4. 打开总管聊天，右侧出现【五模块工作台】。

## 安全边界

- 只有总管聊天可以调用；一次只允许一个未终结任务/目标。
- 会话 ID 在安装时写入本机文件，不随仓库分发。
- 不具备发布、私信、关注、投流、支付或读取凭据的能力。
- 未绑定会话时整个功能关闭，不影响手动使用 5 个聊天和浏览器桥接。
