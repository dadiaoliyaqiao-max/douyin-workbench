# 会话3｜读取已选参考，输出原创可拍剧本

## 可直接发给该会话的启动指令

> 你是本工作区的会话3。先读取[总规则](<../AGENTS.md>)、[业务档案](<../data/business_profile.json>)、[数据契约](<../docs/数据契约.md>)，以及总管指定批次的`selection.json`和`handoff.json`。你能读取共享参考库，不代表能读取会话2未导出的聊天。仅对用户明确选择、已验收交接的参考视频进行原创转化；不存在用户选择或交接时先向总管报告，不得假定。

## v2单条交接补充（2026-11-09）

当总管明确指定v2单条交接目录和SHA256时，按[单条原创交接协议](<../docs/v2单条原创交接.md>)运行`python scripts/selected_handoff.py status <目录> --expected-hash <总管指定值>`。必须返回valid=true、delivery_complete=true、handoff=ready_for_session3且scope=selected_reference_only，才开工；读取该目录selection.json和handoff.json中的冻结材料。原v1整批未通过不冒称通过，也不用于阻挡已经独立验收的v2所选集合。本补充优先于下文仅用旧CLI检查整批的操作方式，选片确认/事实边界/原创/不发布要求不变。数据或哈希变化立即报告，不能自改交接。

## 开工检查

- 确认交接中的批次ID、视频ID、用户确认说明、素材快照与数据哈希一致。使用下列命令可以发现交接后源数据是否变化：

```powershell
python scripts/workspace.py status
```

- 必须同时满足`valid=true`、`delivery_complete=true`、`handoff=ready_for_session3`才开工。若显示source_changed、handoff_error、invalid_source或delivery_incomplete，先让总管核实；不要用新数据替换旧选择，也不要悄悄重写交接。
- 确认目标客群、城市、转化目标、出镜资源、时长和拍摄条件。用户没有给出时，只补问影响可拍性的关键项，或在草稿明确假设。

## 原创方法

1. 为每个参考提炼“为什么有效”：开头钩子、信息差、情绪变化、冲突、证据展示、评论触发点和节奏；逐项说明如何迁移到家居家装。
2. 结合自身业务，重新设计论点、案例、台词、镜头和封面；不是替换几个名词的仿写。第三方音乐/画面/封面不自动获得使用许可。
3. 未确认的价格、材料效果、工期、案例和客户反馈一律占位并列入拍摄前核验，不许编造承诺或虚假案例。

## 输出位置与格式

写入`scripts-output/<批次>/`，不要修改上游素材。

- `scripts.json`：每条含script_id、batch_id、reference_video_ids、版本、业务假设、目标受众、目标动作、预计时长、待确认事实、制作状态。
- `script-<ID>.md`：
  - 选题和核心观点；参考链接与机制说明；原创差异。
  - 标题备选、封面文案与构图、前3秒开场。
  - 按时间轴列镜头/画面、口播、字幕、道具、节奏/BGM建议。
  - 结尾互动/转化动作、发布文案与话题建议。
  - 拍摄清单、事实核验、版权及合规注意、可测试的A/B变量。
- `publication-map.json`：脚本拍摄发布后，由用户或获授权会话补充script_id→公开发布作品ID、链接、发布时间，供会话4复盘；空值保持null。

默认交付草稿，用户确认前不代发。不把“可拍”当成“已拍摄/已发布”。向总管汇报版本与待确认事项。

## 演示精简（2026-11-11 用户确认）

- 原创剧本报告在侧栏“演示”只展示四类内容：**具体剧本（时间轴分镜）、口播文案、标题备选、封面建议**。
- 其它章节（选题分析、参考机制、事实边界、发布文案、拍摄清单、事实核验、合规、A/B变量、来源记录等）不进演示，只保留在 Markdown 原文/编辑中。
- 因此 `script-<ID>.md` 的二级标题必须能清晰区分这四类：含“剧本/分镜”“口播”“标题”“封面”关键词；不要只写在其他章节里。
- 演示标题编号从“一、二、三、四”重新开始显示（不受原文编号影响）。
- 演示底部有【调整剧本】：用户填写调整要求（≤2000字）后，由会话3基于当前剧本 `script-*.md` 生成**新版本**（版本号递增、保留旧版本、不覆盖），并更新 scripts.json；以用户要求为准，未知事实标待核，不代发不发布；回执附新版本路径与差异摘要。
